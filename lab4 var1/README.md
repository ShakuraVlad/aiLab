## 2. Цель лабораторной работы

Цель работы — разработать приложение для оценки вероятности осадков по трём погодным параметрам: температуре воздуха, влажности и атмосферному давлению. Для обработки входных данных необходимо реализовать нечёткий вывод по алгоритму Мамдани, а также создать интерфейс для ввода значений и просмотра результатов.

## 3. Описание предметной области

На вероятность выпадения осадков влияет несколько метеорологических факторов. Например, высокая влажность указывает на большое содержание водяного пара в воздухе, а пониженное атмосферное давление нередко связано с неустойчивой погодой. При этом по одному параметру нельзя однозначно определить, будут ли осадки.

Для данной задачи использована нечёткая логика. В отличие от обычной логики, в которой условие может быть истинным или ложным, нечёткая логика допускает промежуточные степени принадлежности от 0 до 1. Поэтому одна температура может одновременно считаться частично умеренной и частично высокой.

Разработанная система является учебной моделью. Её процентный результат показывает оценку по выбранным правилам, а не статистически подтверждённую вероятность реального дождя.

## 4. Описание входных и выходных переменных

В программе используются три входные переменные и одна выходная.

| Переменная | Диапазон | Лингвистические значения |
| --- | --- | --- |
| Температура воздуха | от -30 до 50 °C | низкая, умеренная, высокая |
| Влажность воздуха | от 0 до 100 % | низкая, средняя, высокая |
| Атмосферное давление | от 950 до 1050 гПа | низкое, среднее, высокое |
| Оценка вероятности осадков | от 0 до 100 % | низкая, средняя, высокая |

Каждому лингвистическому значению соответствует функция принадлежности. Для температуры, влажности и давления используются пересекающиеся нечёткие множества, что обеспечивает плавное изменение результата при изменении входных данных.

## 5. Выбранный язык программирования, технологии и библиотеки

Приложение разработано на языке Python. Для реализации использованы следующие библиотеки:

- Streamlit — создание веб-интерфейса с полями ввода, кнопкой расчёта и отображением результатов.
- NumPy — вычисление степеней принадлежности, выполнение операций над массивами и численное интегрирование.
- Matplotlib — построение графиков функций принадлежности.

Основной код находится в файле `app.py`. Файл `requirements.txt` содержит список необходимых библиотек. Программа запускается локально через команду `py -m streamlit run app.py`.

## 6. Графики функций принадлежности

Для построения нечётких множеств в программе применяются треугольные и трапециевидные функции принадлежности. Их значения изменяются от 0 до 1.

Параметры функций заданы следующим образом (в скобках указаны точки треугольника или трапеции):

| Переменная | Низкая / низкое | Средняя / умеренная | Высокая / высокое |
| --- | --- | --- | --- |
| Температура, °C | трапеция (-30, -30, 0, 15) | треугольник (5, 20, 35) | трапеция (25, 40, 50, 50) |
| Влажность, % | трапеция (0, 0, 25, 50) | треугольник (30, 55, 80) | трапеция (60, 85, 100, 100) |

При выполнении расчёта программа отображает четыре графика: для температуры, влажности, давления и вероятности осадков. На графиках входных переменных отмечается введённое значение. На выходном графике показываются агрегированное нечёткое множество и положение центроида.

Для оформления печатного отчёта: после запуска приложения можно добавить сюда снимки четырёх графиков из раздела «Функции принадлежности». В текущем README приведены точные параметры, по которым эти графики строятся.

## 8. Описание алгоритма Мамдани

Алгоритм нечёткого вывода состоит из пяти основных этапов.

1. Фаззификация. Введённые числовые значения преобразуются в степени принадлежности нечётким множествам. Например, температура 20 °C имеет степень принадлежности 1 к множеству «умеренная», а к множествам «низкая» и «высокая» — 0.

2. Вычисление активности правил. Для каждого правила вычисляется степень выполнения его условий. Для AND используется минимум, для OR — максимум. Например, если влажность принадлежит множеству «высокая» со степенью 0,8, а давление множеству «низкое» со степенью 0,6, то активность правила с AND будет равна 0,6.

3. Импликация. Функция принадлежности выходного множества каждого правила ограничивается сверху степенью его активации. В реализации используется операция минимума.

4. Агрегация. Все полученные выходные функции объединяются в одно нечёткое множество. Для объединения используется операция максимума.

5. Дефаззификация. Итоговое нечёткое множество преобразуется в одно число методом центроида — вычислением центра тяжести:

`y* = ∫ y · μ(y) dy / ∫ μ(y) dy`

Здесь `μ(y)` — агрегированная функция принадлежности, а `y*` — итоговая оценка вероятности осадков. В программе интегралы вычисляются численно с помощью `numpy.trapezoid`. Если площадь агрегированного множества равна нулю, приложение сообщает, что результат получить не удалось.

## 9. Описание интерфейса пользователя

Интерфейс приложения реализован с помощью Streamlit. В верхней части страницы находятся три поля для ввода температуры, влажности и давления, а также кнопка «Рассчитать прогноз».

После нажатия кнопки программа показывает:

- числовую оценку вероятности осадков в процентах;
- текстовую категорию: низкая (меньше 35 %), средняя (от 35 до менее 65 %) или высокая (от 65 %);
- степени принадлежности входных значений;
- четыре графика функций принадлежности;
- таблицу правил и степени их активации.

Поля ввода ограничены допустимыми диапазонами. Дополнительно программа проверяет, что значения являются конечными числами. Пользователь может изменить параметры и повторить расчёт без перезапуска приложения.

## 12. Анализ полученных результатов

Результаты соответствуют логике заданных правил. При высокой влажности и пониженном давлении активируются правила, повышающие оценку вероятности осадков. При низкой влажности и высоком давлении чаще активируются правила, связанные с низкой оценкой.

Преимущество нечёткой системы заключается в том, что небольшое изменение температуры, влажности или давления обычно не приводит к резкому переключению между двумя фиксированными ответами. Благодаря пересечению функций принадлежности одновременно могут работать несколько правил с разной силой.

При этом модель имеет ограничения. Она учитывает только три показателя, а правила и границы нечётких множеств заданы вручную. В настоящем прогнозировании также важны движение воздушных масс, облачность, ветер и другие данные. Поэтому результат следует рассматривать как демонстрацию алгоритма Мамдани, а не как точный прогноз погоды.

Также создан интерактивный интерфейс, в котором можно вводить погодные параметры, запускать расчёт, просматривать числовой и текстовый результаты и анализировать графики функций принадлежности. На нескольких тестовых сценариях проверена работа расчётной части программы.
